# layer2_learnings — 学び・事故記録（Layer 2）

**同じ失敗を繰り返さないための教訓**を置く場所です。

## 役割

`layer2_skills/`（手順書）と対になる「読む知識」の層。
手順書が「どうやるか」なら、こちらは「なぜそうするか／何にハマったか」を残す。

単発の学び・教訓はここに留める（＝Layer 3 には昇格させない）。
繰り返し起動したくなるワークフローだけが Layer 3 の実行スキルになる。

## 命名規則

```
layer2_learnings/YYYY-MM-DD_<テーマ>.md
例: 2026-04-07_pull失敗の真因.md
    2026-05-13_確定値と推定値の二段運用.md
```

## 中身のフォーマット（推奨）

```markdown
---
title: <学びのタイトル>
type: learning
created: YYYY-MM-DD
source: "[[layer1_logs/YYYY-MM-DD_元ログ]]"
---

# <学びのタイトル>

## 何が起きたか
-

## 真因
-

## 今後どうするか（再発防止）
-
```

## 使い方

- AI との認識ズレが繰り返されるものは、教訓としてここに残しつつ
  `CLAUDE.md` の「作業ルール」にも1行追記して規律化する
