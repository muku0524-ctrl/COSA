# layer1_logs — 生ログ（Layer 1）

Claude との作業セッションを記録する「生データ」置き場です。

## 役割

パイプラインの最下層。**その日やったこと・決めたこと**が残ればOKの書き捨てメモ。
量が多く「生」なぶん、そのままでは使いにくい ── それでOK。価値あるものだけが上の層へ昇る。

## 命名規則

```
layer1_logs/YYYY-MM-DD_作業名.md
例: 2026-04-04_旬DB設計.md
    2026-04-01_OEM商談.md
```

## 使い方

- セッション終了時に `daily-log` スキル（「今日の作業をまとめて」）で自動生成する
- ログは書き捨てでOK。丁寧に整える必要はない
- 同じ作業が2〜3回登場したら `layer2_skills/` に手順書として昇格させる
- AI とのズレがあれば記録しておく。あとで `CLAUDE.md` の作業ルールに反映できる

## 昇格先

- 繰り返す手順 → `layer2_skills/`
- 重要な気づき・失敗の教訓 → `layer2_learnings/`
