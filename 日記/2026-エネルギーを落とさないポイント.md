## 一文

> **本当の意味** … **身だしなみを整え、仕事に行ける自分の状態で外に出る。**  
> **最小** … 1日1度外（買い物等）— **出ないよりマシ**。  
> **増幅** … 運動 → 風呂 → リフレッシュ → 軽いメイク → **鏡で自覚**。（本人 · 2026-07-01）

## 思い切り印とは

| | |
|--|--|
| **問題** | いいこと・正しいと思ったことがあった **のに、忘れてしまう** |
| **対策** | そのときの気持ちを **思い切り印** として残す |
| **例** | **30回分チケット購入**（2025/11）— 「外に出て体と仕事を整える」という **当時の自分への約束** |
| **他の印** | 週4スケジュール、日記、このノート、**やった分** のカウント |

**印 ＝ 義務の枷 ではなく、忘れた未来の自分への手紙。**

去年チケットを使わなかった → 印は残ったが **中身（外に出る）** が抜けた → 嫌悪感。  
今年は **印 ＋ 外に出る行為** をセットで回す。

## 続けられなくなったとき — いまいちな選択（本人 · 2026-07-01）

> **何らかの事情で、それが続けられなくなる。**  
> **振り返ると、「続けられなくなっている方」＝丸ごと止めた方が、いまいちな選択だった。**（本人）

| パターン | 例 | 結果（振り返り） |
|----------|-----|------------------|
| **印は残す・中身が止まる** | 2025/11 チケット購入 → **行かない** | 嫌悪感。印だけが **呪い** になる |
| **週4が崩れる → 全部やめる** | 旅行・仕事立て込み → ヨガも外も **—** | エネルギー **さらに落ちる** |
| **「できなくていいや」に寄る** | そこそこが苦手 → **停止** を選ぶ | 後から見ると **最悪寄り** |

**学び:** 事情があって **フル（週4・ヨガ・3食）** が無理なとき、  
**止める** より **縮小して中身だけ守る** 方が、いつもマシだった。

| いまいち（止める） | マシ（縮小継続） |
|--------------------|------------------|
| 週4 → **全部 —** | 週4 → **外 ○ 1回/週** でも |
| ヨガ — → **家から出ない** | ヨガ — → **散歩・用事で外 ○** |
| 食準備 — → **抜き続け** | 食準備 — → **1食 〜** から |
| 印を **忘れる・嫌う** | 印を **読み返して最小に落とす** |

→ **そこそこ頑張る** が難しい性格ほど、**「止める」か「フル」の二択** に寄りやすい。  
**第三の選択＝縮小継続** を、印の横に **明示的に書いておく**。

### 縮小継続の最小ライン（夏）

| 軸 | フル | **最小（止めるよりマシ）** |
|----|------|---------------------------|
| 外 | 週4・ヨガ拠点 | **週に1回、外 ○** |
| 食 | 食準備 ○ | **1食 〜** |
| 印 | スケジュール通り | **このノートを開く** だけでも |

**事情で崩れた週** ＝ 失敗 **ではない**。**フルに戻す前の、縮小モード**。

## 締め切りモード（本人 · 2026-07-01）

> **締め切りを抱えると、その数日間、何かを止めてしまう。**  
> **体もめちゃくちゃしんどい。**

| 止まりやすいもの | 締め切り期の実態（6月型） |
|------------------|---------------------------|
| 運動 | ○ が急減 |
| 身だしなみ＋**本当の外出** | 毎日は **できていない** |
| 食 | ご飯は **作っている**（完全停止ではない） |
| 外（最小） | **買い物**（誰にも会わない）程度は **している** |

→ **丸ごとゼロ** ではないが、**フルが一気に縮む** パターン。  
運動分析の「立て込み → パワー枯渇 → 運動 —」と **同型**（[[日記/2025-02_2026-06-運動-分析#分析結論：運動空白 ＝ 仕事の立て込み]]）。

**締め切り中のルール（新）:**

1. **フルは求めない** — 締め切りモードを **自覚** する
2. **〜（最小外出）** でも **止めるよりマシ** — 買い物 ○ は **成功**
3. **締め切り明け** に **身だしなみ＋拠点（ヨガ）** へ **意図的に戻す** — 6月のように **止めたまま** にしない

## 「外に出る」の段階 — 3レベル

本人が **わかっている本当の意味** と、**締め切り期の現実** を **両方** 書いておく。

| Lv | 記号 | 内容 | 位置づけ |
|----|------|------|----------|
| **0** | **—** | 出ない | 締め切り期に **増えやすい** |
| **1** | **〜** | **最小外出** — 買い物等、**誰にも会わない**。ご飯は作る | **出ないよりマシ**（締め切り期でもここまで来ている） |
| **2** | **○** | **本当の意味** — **身だしなみ** を整え、**最低限仕事に行ける自分** の状態で出かける | **毎日はできていない** が、**目指す中身** |
| **3** | **◎** | **拠点フル** — 下記「鏡・自覚ループ」付き（ホットヨガ等） | 夏の **増幅** |

**日記:** `外: 〜` でも **責めない**。**やった分** として数える。  
**印の中身** は Lv2。**締め切り中は Lv1 を最小ライン** に落とす。

## 鏡・自覚ループ — 本当に効いているもの

> ホットヨガ … 運動 → **お風呂** → リフレッシュ → **軽いメイク** → **鏡** で自分を見る → **いろいろな意味で自覚** — **良い**。（本人）  
> **Pilates Mirror**（ミラーでやるピラティス）も **同型の効果** あった。  
> 筋トレにもミラーはあるが、**効き方はやや弱い**。（本人 · 2026-07-01）

```
運動（きっかけ）
    ↓
体を整える（風呂・温泉）
    ↓
身だしなみ（軽いメイク等）
    ↓
鏡で自分を見る → 自覚（「自分」に戻る）
    ↓
仕事に行ける状態 · エネルギー維持
```

| 種目 | 鏡 | 風呂/整える | 自覚の効き |
|------|-----|------------|------------|
| **ホットヨガ拠点** | ○ | **温泉** | **強い** |
| **Pilates Mirror** | **メイン** | — | **強かった** |
| **筋トレ（Element）** | あり | シャワー | **やや弱い** |

→ 「外に出る」＝ **場所移動** だけでなく、**鏡で自分を取り戻す儀式**。  
チケット・週4 ＝ その儀式を **起動する印**。

**締め切り明けの復帰** … Lv1（買い物）→ Lv2（身だしなみ外出）→ Lv3（拠点）の **順** で戻す。

## エネルギーを落とさないポイント

```
締め切り · 家に閉じる
    ↓
Lv0 —  … 体めちゃくちゃしんどい
    ↓
Lv1 〜  … 買い物（人に会わない）— 出ないよりマシ
    ↓
Lv2 ○  … 身だしなみ＋仕事に行ける自分で外出（本当の中身）
    ↓
Lv3 ◎  … 運動→風呂→メイク→鏡（ホットヨガ拠点）
    ↓
パワー維持 · 仕事も捗る
```

| レベル | 夏の目安 |
|--------|----------|
| **締め切り中** | **Lv1 〜** を維持（止めるよりマシ） |
| **通常** | **Lv2 ○** を目指す（毎日でなくてよい） |
| **週4スケジュール** | **Lv3 ◎** の日を **先に決める**（思い切り印） |

→ 週4は **運動の義務** というより、**鏡・自覚ループを起動する日** をカレンダーに刻む行為。

## 日記での書き方

**毎日（最小2行）:**

```
- **外に出た**: — / 〜 / ○ / ◎
- **ホットヨガ**: ○ / —
```

| 外 | 意味 |
|----|------|
| **—** | 出ない |
| **〜** | 最小（買い物・人に会わない）— **締め切り期のライン** |
| **○** | 身だしなみ＋仕事に行ける状態で外出 |
| **◎** | 拠点フル（ヨガ＋風呂＋メイク＋鏡）— ヨガ ○ 日は **◎** でよい |

| 外 | ヨガ | 読み方 |
|----|------|--------|
| ◎ | ○ | **理想** — 鏡・自覚ループ |
| ○ | — | **本当の外出** 達成 |
| 〜 | — | **締め切り期でも成功** — 止めるよりマシ |
| — | — | **翌日 〜 から** 再開（責めない） |

**週末:** 「外 〜/○/◎ ○ 日」だけ数える（やった分）。
