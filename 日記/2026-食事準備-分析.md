## 要約（3行）

1. **日記に食事の記録はほぼない** — これから **俯瞰用の1行** を足して、運動・本線と **並べて見る**。
2. **食事準備は「体調の土台」** の可能性が高い。4〜5月の体調◎は運動だけでなく、**学校期の生活リズム**（子ども昼食＝自宅負荷が少ない）も効いていたかもしれない。
3. **7〜8月は負荷が跳ね上がる** — 長期休暇で **毎食が自宅**。ホットヨガと **同じくらい先にスケジュールを組む** 対象。

## 体とパワーとの位置づけ

運動分析（[[日記/2025-02_2026-06-運動-分析]]）のモデルに **食事** を足す。

```
【土台】食事準備 ○
    ↓ 燃料・血糖・家族の安定
やる気・パワー（本線）
    ↓
運動 ○ ／ 仕事
    ↓
体調
```

**逆方向（悪循環）:**

```
仕事立て込み ＋ 夏休み（毎食）
    ↓
食事準備 おろそか（—）
    ↓
体調・パワー ↓  … コンビニ・抜き食い・夜遅い
    ↓
運動 — ／ 本線 脱線
```

→ **運動だけ増やしても、食事が — だと体調は頭打ち** になりうる。4〜5月は **運動＋（推定）生活リズム** のセットだった可能性。

## 学校期 vs 夏休み — 負荷の見積もり

| | 4〜6月（学校期） | 7〜8月（長期休暇） |
|--|------------------|---------------------|
| **子どもの食事** | 昼は **学校**（自宅で作るのは主に朝・夜） | **朝・昼・夜 すべて自宅** |
| **負荷感** | 相対的に **区切りがある** | **毎日が連続** — 「今日もまた」 |
| **本人の食事** | おろそかでも **マシに回っていた** かも | おろそかが **そのまま体調に出る** |
| **日記上の言及** | ほぼなし | 「食事を作ること **山積み**」（7/1） |

**仮説（要・記録で検証）:** 6月の消耗 ＝ 仕事立て込み **＋** 期末〜夏にかけて **食事の質が落ち始めた** 二重。7月は **食事負荷が構造的に増える** ので、先に枠を作る。

## 日記での書き方（1行）

テンプレ: [[templates/daily-note#食事準備]]

| 記号 | 意味 | 例 |
|------|------|-----|
| **○** | **食準備できた** — 家族の食事を **意図して** 用意した（自炊・仕込み・定番の完成） | 朝晩セット、週末のまとめ作りで平日 ○ |
| **〜** | **一部** — 1食だけ、簡易（冷凍・レトルト＋野菜）、自分だけ — | 「昼は — 、夜 ○」→ **〜** |
| **—** | **おろそか** — 抜き・コンビニ・デリバリー中心、準備なし | |

**書き方のコツ**

- **完璧にしない** — ○ は「100点の献立」ではなく **「準備した日」**
- **ひとこと** は任意（「弁当いらない週なのに夜だけ —」など）
- **残り・罪悪感は数えない** — 運動と同じ。**やった分（○）** を週末に数える

## 週次の俯瞰（Cursor か Obsidian で）

毎週日曜 or 月曜に、直近7日を **3列** で並べる。

| 日 | 本線 | 食準備 | 運動 |
|----|------|--------|------|
| 月 | | | |
| … | | | |

**見るポイント**

1. **食 — が続く週** → 本線・体調はどうだったか？
2. **食 ○ なのに本線 脱線** → 仕事要因（6月型）
3. **食 ○ ＋ 運動 ○** → 体調◎に近い週か？

月次は **○ の日数** だけ（`7月 食準備 ○ 12日`）。**— の日を責めない**。

## アドバイス — 性格・生活に合わせて

### 1. ホットヨガと同型で組む

あなたは **枷をバネ** にするタイプ。**食事も「毎日フルコース」ではなく、自分で決めたスケジュール** が向く。

| 向かない | 向く |
|----------|------|
| 「毎日3食ガチ自炊」義務 | **週次の献立テンプレ**（月水金同メニュー等） |
| 残り食材のカウントダウン | **○ を数えた週** |
| 崩れたら放弃 | **翌日1食から ○**（組み替え） |

### 2. 夏休み用 — 最小ライン

**週の骨格**（例 — 本人の生活に合わせて調整）:

| 枠 | 内容 |
|----|------|
| **週1回** | まとめ作り（肉・味付け、野菜洗い切り）→ 平日 **〜 でも ○ に近づく** |
| **定番3〜5品** | ローテ（カレー、丼、パスタ、焼 fish、鍋）— **決めるのをやめる** |
| **昼** | 子ども向け **固定セット**（おにぎり＋卵＋フルーツ 等）— 考えない |
| **自分** | 子どもと **同じ土台** でよい。別メニューは **週末だけ** |

**〜 も成功** — 「1食 ○」で週の ○ 1 増やす。全部 — より **はるかにマシ**。

### 3. コワーキング日（ホットヨガ ○ 日）との連動

[[日記/2026-07-01]] … 温泉・コワーキングで **体が整い仕事も捗る**。

| パターン | 提案 |
|----------|------|
| **外出 ○ 日** | 前日夜 or 朝 **仕込み ○** → 帰宅後は **〜** でよい |
| **家にいる — 日** | 逆に **昼 ○** を狙う（ヨガ行かない日＝キッチンにいる日） |

→ 運動スケジュール（月水金土）と **食の仕込み日** を **同じカレンダー**（[[日記/2026-07-ホットヨガ-スケジュール]] の横に「仕込み」列）に書いてもよい。

### 4. 本線との読み方

| 食準備 | 本線 | 読み方 |
|--------|------|--------|
| — 続き | 脱線 | **燃料不足** の疑い — まず1食 ○ |
| ○ 続き | 本線 | **好循環** — 4〜5月型の再現候補 |
| ○ なのに | 脱線 | **仕事要因** — 食は守れている（6/22〜25型） |
| — なのに | 本線 | 仕事は動くが **体の余裕は別** — 6月後半の消耗 |

### 5. 記録を始めるタイミング

- **7/1 から** 食準備 1行を追加（運動と同じ）
- **2週間** 後に初回俯瞰 — Cursor に「7月前半の食事と本線を並べて」と依頼
- **8月末** に運動分析と **突合** — 夏ブロックの総合レビュー
