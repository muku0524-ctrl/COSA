#### ⑤ HeaderBar 右上にペイン折りたたみグループを集約（`HeaderBar.tsx`）

「最終台本を書く時に台本に集中しやすいから、1 / 2 / 3 ペインがたためる右上ボタンが欲しい」という要望:

```
... ペイン [Pane1 Pane2 Pane3] | 台本集中モード | 流れの図解 | 下書き保存 | 下書き消去 | i
```

- `Pane1Toggle` を左端からこのグループに移動
- `PaneCollapseToggle` で Pane 2「選ぶ」 / Pane 3「決める」を追加
- `pane2Collapsed` / `pane3Collapsed` の state と toggle を `Workspace.tsx` から HeaderBar に props で渡す
- 既存のペイン内ヘッダートグルはそのまま維持（ペインを見ながらでも畳めるルートを残す）
- 台本集中モード中はこのグループ自体を非表示（Pane 1〜3 がそもそも消えるため）

「台本集中モード」と「個別折りたたみ」の使い分け:
- **集中モード** = 一気に Pane 1〜3 を完全非表示、Pane 4 全幅
- **個別折りたたみ** = 1 つだけ畳んで細い縦レールに（情報は残しつつ作業領域を広げる）

### 今日の事件 — 「v5 台本が画面に反映されていない」

#### 症状

ユーザーから「台本部分を全て変えてと言いましたが変わっていないのはなぜ」。`data/isshi-souden.json` の `scripts[*].na` には v5 本文が入っているのに、画面の textarea は別の（または空の）内容を表示していた。

#### 原因

`app/page.tsx` の以下の分岐:

```ts
const localPath = join(process.cwd(), "data/isshi-souden.local.json");
const useLocal =
  process.env.ISSHI_PUBLIC_BUILD !== "1" && existsSync(localPath);
const raw: unknown = useLocal
  ? JSON.parse(readFileSync(localPath, "utf-8"))
  : defaultDocument;
```

`isshi-souden.local.json`（個人ローカル編集用、`.gitignore`）が存在すれば **そちらを優先** する。私は同梱サンプルの `isshi-souden.json` ばかり書いていて、`local.json` は 5/30 20:40 時点の古いコピー（`na: ""` ／新フィールド無し）で固まっていた。

#### 対処

1. 旧 `data/isshi-souden.local.json` を `.bak.20260531-002753` として退避
2. `node scripts/compose-prep-local.mjs` を実行（`isshi-souden.json` → `isshi-souden.local.json` の単純コピー）
3. ブラウザの HTML を `curl` で検証:

```
トキアソウ  9 回
ＶＩＤＥＯ  6 回
ＡＵＤＩＯ  6 回
蒸気が当たった  3 回
頭を丸めてきた  3 回
工程図解  2 回

```

ようやく v5 が画面に出るようになった。

## 考えたこと

- **「データソースの二重化」は時限爆弾**。`local.json` 優先という仕組み自体は伏字サンプルとローカル個人データを分けるための正しい設計だが、開発者（=私）が同梱サンプルだけ更新して `local.json` を放置すると、見える結果と書いたコードがズレる。長期的には `isshi-souden.json` 更新時に `local.json` も追従させる仕組み（または「local がサンプルより古い時に dev サーバー起動時に警告」など）が要る
- **判断（選ぶ）と素材（集める）は「Why → What」の順** で並べると迷わない。Pane 2 の最上部に「工程図解」を置いたら、その下の「捨てる／残す」が一段使いやすくなった気がする。**「考える前に思い出す」ステップを UI に物理的に置く** という発見
- **「左右に書く」と「上下に書く」は読み筋が違う**。横グリッドは「カタログ的に見渡す」、縦フローは「順番に教える」。同じ `CraftProcessOverview` でも `direction` ひとつで意味が変わる
- **集中モードと個別折りたたみは別物**。「全部隠して 1 つに集中」と「1 つだけ畳んで隣を広げる」は意図が違うので、ボタンも別レイヤーに分けたほうがよい
