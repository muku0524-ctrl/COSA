## ログ

### GitHub に自分の保管場所を作った
- `git-workspace1`（private）を GitHub に新規作成し、現在のプロジェクト（一志相伝ワークスペースなど）を push した
- URL: https://github.com/muku0524-ctrl/git-workspace1
- これまで Gitea に向いていた `origin` を GitHub に切り替え、Gitea は `gitea` という名前で残した

### Git の基本を理解した
- **commit** = パソコンの中でセーブする
- **push** = GitHub に送る
- commit だけでは GitHub にはまだ届かない。最後に push が必要

### Cursor の中で Claude を固定で使えるようにした
- チャット入力欄の `Auto ▼` → `claude-4.6-sonnet` に変更
- Cursor はもともと Claude が入っているが、Auto だと軽いモデルに自動切替えされることがある。固定にすることで会話が安定した
- Cursor = スマホ本体、Claude = 中のアシスタント、という理解

### Cursor の便利設定を入れた
- **日本語ルール**: Cursor Settings → Rules → User → New → `必ず日本語で答えてください。` を保存
- **自動保存**: VS Code Settings → Auto Save → `afterDelay` に変更
- どちらも一度設定すれば以後ずっと有効

### 毎朝 8 時の日記リマインダーを設定した
- 8 時に Mac が通知 → Cursor で COSA が開く → クリップボードにプロンプトがコピーされる
- あとは `⌘L` → `⌘V` → Enter の 3 キーで AI が昨日の日記を書いてくれる
- 朝以外でも「昨日分をまとめて」と頼めばいつでも動く

## 考えたこと
- GitHub に保存することで「パソコンが壊れても安心」「間違えても前の状態に戻せる」という感覚が初めて実感できた
- Cursor と Claude の関係がずっとモヤっていたが「スマホとSiri」のたとえで一気にクリアになった
- Auto → Claude 固定にして会話がスムーズになった感覚は気のせいではなかった。軽いモデルと会話特化モデルの差
- 「スキルを育てる」= AI への仕事マニュアル（Rules）を育てること。Cursor Rules と `.claude/skills/` の 2 層構造がある
- 全作業を自動で日記化する機能は今の Cursor にはない。「頼んだら動く助手」として使う習慣を作ることが大事
- COSA（メモ用）と workspace-ui-kit（コード用）は別の引き出し。Cursor は 1 ウィンドウ = 1 引き出し
