### Obsidian × Cursor の仕組みを理解した

#### 仕組みの整理
- Cursor はこのプロジェクト（workspace-ui-kit）での全チャットをファイルに保存している
- 「まとめて」と頼むと、Claude がそのファイルを読んで日記を書く
- どのセッションでも・どんな時間差があっても記録を読み返せる
- ただし「このワークスペース内だけ」「Cursor 以外（スマホの Claude など）は見えない」

#### Obsidian と Claude の役割分担
| 役割 | 担当 |
|------|------|
| 書く・まとめる | Claude（頼んだときだけ） |
| 保存・表示する | Obsidian |
| ファイルの存在に気づく | Obsidian（自動・数秒〜数十秒） |

#### やることは2ステップだけ
1. 仕事をする
2. 「まとめて」と頼む（好きな時間・どのウィンドウからでも可）

### Obsidianの記録に感動
- 日記が自動でまとめられていることに感動した
- 「チャットで質問したことも残せるか？」→ 「まとめて、質問も」と一言足せばOK

## 質問したこと

| 質問 | 答え |
|------|------|
| Obsidianは少ししたら自然に書いてくれるの？ | いいえ。Claude が書く。Obsidianは表示するだけ |
| どのチャットからでもやったことがわかる？ | このワークスペース内の全チャットが見える |
| チャットの質問も残せる？ | できる。「質問も」と一言足すだけ |
| Anthropic と OpenAI は同じ？ | 別会社。ChatGPT系（OpenAI）vs Claude系（Anthropic） |
| OpenAI のクレジットを以前買った → 使える？ | API キーがあれば使える |

## 考えたこと
- Obsidianは「書いてくれるもの」ではなく「Claude が書いたものを見せてくれるもの」という理解が固まった
- チャット内容が全部記録されていて、いつでも振り返れるのは強い。「先週やったこと」でも対応できる
- OpenAI のキーが使えれば Anthropic のクレジット購入をスキップできる
