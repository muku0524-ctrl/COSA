### AIスクール第6回講義（スマホ・iCloud メモより）

#### 学んだ概念
- **GitHub とリポジトリの仕組み**：GitHub はコード版 Google Drive。リポジトリ = 1プロジェクトの箱、クローン = 箱を自分の PC に持ってくる、コミット = PC 上でセーブ、プッシュ = GitHub に送る
- **.gitignore と .env の役割**：.gitignore は「GitHub に上げたくないファイルの除外リスト」。.env は「API キーを保管する金庫ファイル」。セットで使う
- **CLAUDE.md と SKILL.md**：CLAUDE.md = AI に毎回言わなくていいよう事前に伝えるメモ。SKILL.md = AI への作業手順書
- **PoC（Proof of Concept）**：本格的に作る前に「できるか試し打ち」すること
- **HTML / CSS / JS / Next.js / Vercel の関係**：HTML が骨格・CSS が見た目・JS が動き。Next.js はそれをまとめて効率よく作る道具セット。Vercel は世界に公開できる場所
- **pnpm dev**：自分だけが見れる開発モードで起動（ localhost）
