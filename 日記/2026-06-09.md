## 私が理解できたこと（今日の学び）

### 講義7の本質

- 今月のテーマは **「自分のツールに記憶を持たせる」**
- 月次課題は **DB連携して Vercel 公開**（全部DBにしなくていい）
- データの置き場所を選ぶこと自体が **ハーネスエンジニアリング**

### データの置き場所（自分用の設計）

| 場所 | 入れるもの |
|---|---|
| Neon（DB） | ブラウザで編集して残したい下書き |
| JSONファイル | ケース別バックアップ（kataoka 等） |
| Git / スキル / 日記 | junin-kosei、COSA、ルール（AIの手元） |

### 技術のたとえ（自分の言葉で）

- **Vercel** … お店をオープンする場所
- **Neon** … お店の帳簿（注文を残す倉庫）
- **local.json** … 自分の机の上のメモ（外には出さない）
- **git commit** … セーブポイント。壊しても戻れる

### 今日の成功の公式

```
準備（commit）→ 設計（何をDBに）→ Vercel公開 → Neon接続
→ コードpush → メール修正 → 再デプロイ → 「DBに保存済」確認
```

一つで止まっても、**原因を特定して次の一手** で届いた。
