# weekly-review — 週次振り返り・次週計画（＋昇格候補の洗い出し）

今週の生ログを読み、成果・学び・来週のアクションをまとめます。
同時に、Layer 1 → Layer 2 へ昇格すべき知識の候補を提案します。

## 実行手順

### Step 1: 今週のインプット収集

以下を読む:

- `layer1_logs/` の今週（過去7日）のログ
- `日記/` の今週分のデイリーノート（あれば）

### Step 2: 週次レビューを出力する

```
## [YYYY年M月第X週] 週次レビュー

### 今週やったこと（完了）
-

### 積み残し（未完了・継続中）
-

### 気づき・学び
-

### 来週のアクション（優先度順）
| # | アクション | 期限 |
|---|-----------|------|
| 1 | | |
| 2 | | |
| 3 | | |

### 今週のひとこと
-
```

### Step 3: Layer 2 昇格候補の提案（このスキルの肝）

今週のログを横断し、以下を提案する:

- **手順書化候補（→ `layer2_skills/`）**: 今週2回以上登場した、または再現性のある手順
- **学び化候補（→ `layer2_learnings/`）**: 繰り返すと危険な失敗・重要な判断基準
- **規律化候補（→ `CLAUDE.md`）**: AI とのズレが繰り返されているパターン

各候補に「なぜ昇格すべきか」を1行添える。ユーザーが承認したものだけ実際に作成する。

## 保存先

週次レビューは `layer1_logs/YYYY-MM-DD_週次振り返り.md` に保存する。

> このスキルは「読む知識（Layer 2）」を増やす入口。ここで挙げた昇格候補が育つと、
> やがて `layer3_skills/_index.md` の基準を満たし、実行スキル（Layer 3）へと昇格していく。
