# 週次昇格プロンプト（Layer 1 → Layer 2）

このパイプラインの心臓部です。**週1回**、その週の生ログを読んで手順書・学びに蒸留します。

## 使い方

以下のいずれかで実行する:

- **手動**: 毎週末、この本文を Claude Code に貼って実行する
- **cron / launchd**: 日曜夜にヘッドレスの Claude を起動し、このプロンプトを渡す
- **クラウドエージェント**: Cursor Cloud Agent 等で毎週スケジュール実行する

---

## プロンプト本文（ここから下を Claude に渡す）

あなたはこの vault の知識管理担当です。今週分の生ログを Layer 2 へ蒸留してください。

### 手順

1. **収集**: `layer1_logs/` の過去7日分のログをすべて読む。
   `日記/` の今週分のデイリーノートも参照する。

2. **抽出**: ログを横断し、以下を洗い出す。
   - **手順書候補（→ `layer2_skills/`）**: 今週2回以上登場した、または明確に再現性のある作業手順
   - **学び候補（→ `layer2_learnings/`）**: 繰り返すと危険な失敗・重要な判断基準・ハマりどころ
   - **規律候補（→ `CLAUDE.md` の作業ルール）**: AI とのズレが繰り返されているパターン

3. **蒸留して書く**: 各候補について Layer 2 のフォーマット（各フォルダの README 参照）で
   ノートを作成する。既存の Layer 2 ノートと重複する場合は、新規作成せず既存ノートを更新する。
   各ノートの frontmatter に `source: "[[layer1_logs/元ログ]]"` を必ず入れる。

4. **昇格候補の報告**: Layer 2 → Layer 3（実行スキル）へ昇格すべきものがあれば、
   `layer3_skills/_index.md` の4基準に照らして判定し、**提案だけ**する（自動昇格はしない）。

5. **サマリー出力**: 「今週作成/更新した Layer 2 ノート」「Layer 3 昇格候補」を箇条書きで報告する。

### 守ること

- 生ログ（Layer 1）は消さない・書き換えない。読むだけ。
- 蒸留は「量を減らして要点だけ残す」こと。ログの丸写しはしない。
- 確信が持てない・再現性が低いものは無理に昇格させず、Layer 1 に留める。
