# layer3_skills — 実行可能スキル（Layer 3）

> 知識昇格パイプラインの最上層。**スキル本体の正本は `.claude/skills/<name>/` に置く**。
> このファイルには昇格基準・昇格手順・昇格記録（MOC）だけを書く。

## 知識昇格パイプライン

```
layer1_logs（生ログ）
  │ 週1回、週次エージェントが自動昇格
  ▼
layer2_skills（手順書）・layer2_learnings（学び）
  │ 昇格基準を満たしたら手動昇格
  ▼
Layer 3 = .claude/skills/（実行可能スキル）
```

- Layer 2 まで = **読む知識**（作業前に Read する手順書・学び）
- Layer 3 = **起動する知識**（トリガーフレーズ / コマンドで呼び出す実行可能スキル）

## 昇格基準（layer2 → Layer 3）

以下を **すべて満たしたら** 昇格候補とする（この門番がスキル棚を「本当に使うものだけ」に保つ）:

1. **起動できるワークフローである** — 「いつ使うか」が明確で、毎回ほぼ同じ手順を踏む。単発の学び・教訓は layer2 に留める
2. **実績がある** — 直近3ヶ月で2回以上、実際にその手順を使った
3. **手順が安定している** — 手順が枯れており、使うたびに書き換えていない
4. **呼び出す価値がある** — トリガーフレーズやコマンドで即起動したい場面がある

## 昇格手順

1. `.claude/skills/promote-skill/SKILL.md` を起動し、SKILL.md ＋ 参照ファイルの構造に変換する
2. `.claude/skills/<name>/SKILL.md` として配置する（`name` と `description` を明記）
3. 元の layer2 ノートは**削除しない**。frontmatter に `promoted_to: .claude/skills/<name>` を追記して残す
4. 下の「昇格記録」に1行追加する

## 現在の Layer 3 スキル一覧

| スキル | トリガー | 内容 |
|---|---|---|
| daily-log | 「今日の作業をまとめて」 | セッション終了時に Layer 1 へ生ログを記録 |
| weekly-review | 「週次レビュー」「今週の振り返り」 | 週次の振り返り＋来週計画。layer2 昇格候補も提案 |
| promote-skill | 「このノートをスキル化して」 | layer2 → Layer 3 の昇格を実行する |
