# 4ペイン画面の開き方

## 開く手順（毎回これだけ）

### ① ブラウザで開く
```
http://localhost:3000
```
→ Chrome か Safari のアドレスバーにそのまま貼り付けて Enter

### ② 画面が出ない・エラーが出る場合 → サーバーを起動する
Cursor の workspace-ui-kit を開いて、ターミナルで：

```bash
npm run dev
```

「Ready in...」と出たら → ① に戻ってブラウザを開く

---

## この画面は何？

- **プロジェクト**: `workspace-ui-kit`（`~/src/workspace-ui-kit`）
- **データ**: `data/isshi-souden.local.json`（一志相伝の台本・テーマなど）
- **フォルダ**: `~/src/workspace-ui-kit`（Cursor で開く）

---

## よくある疑問

| 疑問 | 答え |
|------|------|
| localhost:3000 が開かない | Cursor のターミナルで `npm run dev` を先に実行する |
| どのCursorウィンドウで開くの？ | `workspace-ui-kit` のウィンドウ |
| サーバーを止めたい | ターミナルで `Ctrl + C` |
| 変更してもブラウザに反映されない | ブラウザを再読み込み（⌘R） |
