# inbox — 外部情報の取り込み口

パイプラインの入口（脇役）。外で拾った情報を、いったんここに放り込む場所です。

## 役割

- スマホで拾った記事・メモ・アイデアの一時置き場
- ここに置いたものは、あとで Claude に「inbox を整理して」と頼み、
  内容に応じて `日記/` や `layer1_logs/` へ振り分ける

## 使い方

1. 気になった情報を `.md` や `.txt` でこのフォルダに投げ込む
2. 定期的に Claude に整理を依頼する（適切な層へ振り分け＋不要ファイル削除）

> このフォルダは「一時置き場」。溜め込まず、こまめに振り分けて空にするのがコツ。
